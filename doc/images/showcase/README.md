# Halo product screenshots

Captured on 2026-11-16 from the native Halo GTK interface at commit
`d223dd4`, using an isolated demonstration environment.

| Image | View | Dimensions |
| --- | --- | --- |
| `overview-light.webp` | Overview, light appearance | 1440 × 940 |
| `overview-dark.webp` | Overview, dark appearance | 1440 × 940 |
| `focused-view.webp` | Focused camera view | 1440 × 960 |
| `activity.webp` | Activity and recording playback | 1440 × 960 |
| `security.webp` | Ring Alarm and sensor overview | 1440 × 1090 |

The interface is rendered by the application itself. Camera scenes are
AI-generated fictional imagery; device names, security states, events, health
readings, and active-session states are synthetic. The Activity player uses a
silent local sample derived from the fictional porch image. No private camera
feeds, Ring credentials, or real device commands were used for these captures.
These images illustrate the interface and do not establish live hardware
compatibility.

Screenshots were encoded as WebP for the README. No interface elements were
retouched or composited into the captured application windows.
